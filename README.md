# History Clicker

A procedural incremental game inspired by Civilization.

## Live Version

Play the game directly in your browser: [History Clicker Web](https://github.com/<username>/<repo>/)

*(Note: Once deployed, the URL will be `https://<username>.github.io/<repo>/`)*

## Project Structure

- `web/`: The HTML5/JS web version of the game.
- `HistoryClicker/`: iOS version source code.
- `tools/`: Development and verification scripts.

## Running Locally

To run the web version locally:
1. Navigate to the `web/` directory.
2. Run a simple HTTP server (e.g., `python3 -m http.server`).
3. Open `http://localhost:8000`.
